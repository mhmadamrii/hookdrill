Playlist Builder

Op. 2 Medium 20 points7 public tests

Build a playlist picker in App.jsx (default export App), like adding songs to a playlist in Spotify. The song library is in songs.js.

Requirements

  1. Add. Clicking Add appends the song to the end of the playlist. A song can be in the playlist once; its Add button is disabled while it is. Proved by adds songs to the end of the playlist in click order, disables Add for a song already in the playlist
  2. Reorder. Each playlist item has Up and Down buttons that move it one position. Proved by moves a song up, moves a song down
  3. Boundaries. The first item's Up and the last item's Down are disabled; with a single item, both are. Failing disables Up on the first item and Down on the last item, updates the disabled buttons after reordering Proved by disables Up on the first item and Down on the last item, updates the disabled buttons after reordering
  4. Remove and empty state. Removing a song re-enables its Add button. An empty playlist shows playlist-empty. Proved by removes a song and lets it be added again
