## Requirements

- **Increment**: clicking **+** adds 1 to the count.
- **Decrement**: clicking **−** subtracts 1. The count never goes below 0.
- **Reset**: clicking **Reset** sets the count back to 0.
- The count starts at 0.

## Required `data-testid` selectors

| Test id            | Element                    |
| ------------------ | -------------------------- |
| `count`            | the current count, as text |
| `increment-button` | adds 1                     |
| `decrement-button` | subtracts 1, never below 0 |
| `reset-button`     | sets the count to 0        |
